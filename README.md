# Alzheimer-s-Early-Detection-Using-NLP-on-Speech-Recognition
Developed an AI system that detects Alzheimer's from speech. Used AssemblyAI to convert audio to text, then applied NLP to analyze linguistic patterns linked to cognitive decline. Trained 5 models - Random Forest, SVC, NB-SVC, LSTM, Bi-LSTM - on DementiaBank dataset (117 Alzheimer's + 93 healthy). Best model NB-SVC got 84% accuracy.
